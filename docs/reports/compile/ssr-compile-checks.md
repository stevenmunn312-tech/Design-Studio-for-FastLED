# Solid-state relay compile checks

> **Status: complete.** The Seeed Grove 2-channel solid-state relay fixture
> passed on classic ESP32 on 8 October 2026. This is compile evidence only;
> the module remains experimental in the
> [support matrix](../../release/beta-support-matrix.md) until a recorded
> bench run exists. No AC load has been switched.

The fixture comes from a real Studio graph. A `ButtonInput` on GPIO 4 drives
channel 1 of `RelayOutput` with the Grove 2-channel part selected. Channel 2
is unwired. A solid colour drives an LED output. Fixture generation refuses a
sketch that does not hold both GPIOs low before they become outputs, drive
channel 1 high when the button is pressed, and leave channel 2 off. A third
channel pin is a failure.

The solid-state relay is generated by the normal sketch generator only. The
slideshow and SD-player templates do not evaluate arbitrary output devices, so
there are no fixtures for those paths.

## Reproduce

From the repository root:

```powershell
npm run gen:compile-fixtures -- ssr
python scripts/compile-fixtures/compile-presence-smoke.py arduino-cli backend/sketches/ssr-fixtures/ssr.ino --fqbn esp32:esp32:esp32 --tag esp32 --label ssr
```

The runner uses the helper's real `_compile_upload` path and never flashes. It
writes a log and JSON report beside the generated sketch. `backend/sketches/`
is gitignored, so this page is the durable result. Run compiles one at a time;
they share one arduino-cli workspace.
