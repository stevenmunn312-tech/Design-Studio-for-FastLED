# Cooling-fan compile checks

> **Status: complete.** The Noctua NF-A4x10 5V PWM fixture passed on classic
> ESP32 on 8 October 2026. This is compile evidence only; the fan remains
> experimental in the [support matrix](../../release/beta-support-matrix.md)
> until a recorded bench run exists.

The fixture comes from a real Studio graph. A `PotInput` drives the Speed input
of `CoolingFanOutput`. Its measured RPM passes through `MapRange` into a Gauge
and an LED output. Fixture generation refuses a sketch without the 25 kHz LEDC
setup, falling-edge tachometer interrupt, two-pulse RPM calculation and
published RPM value.

The cooling fan is generated by the normal sketch generator only. The
slideshow and SD-player templates do not evaluate arbitrary output devices, so
there are no fixtures for those paths.

## Reproduce

From the repository root:

```powershell
npm run gen:compile-fixtures -- cooling-fan
python scripts/compile-fixtures/compile-presence-smoke.py arduino-cli backend/sketches/cooling-fan-fixtures/cooling-fan.ino --fqbn esp32:esp32:esp32 --tag esp32 --label cooling-fan
```

The runner uses the helper's real `_compile_upload` path and never flashes. It
writes a log and JSON report beside the generated sketch. `backend/sketches/`
is gitignored, so this page is the durable result. Run compiles one at a time;
they share one arduino-cli workspace.
